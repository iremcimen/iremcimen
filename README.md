## 👩‍💻 About Me

I’m a **Computer Engineering graduate** focused on **backend development with Python and FastAPI**.

I build backend applications with an emphasis on **clean architecture**, **REST API design**, and **scalable system thinking**. I enjoy working on the parts of software that make applications reliable and maintainable — from **authentication and authorization** to **database design**, **caching**, **error handling**, and **Dockerized environments**.

My main backend stack includes **Python**, **FastAPI**, **PostgreSQL**, **SQLAlchemy**, **Redis**, and **Docker**. I also have experience with **Flutter**, which helps me understand the full flow between backend services and client applications.

I’m especially interested in:

- **Backend architecture**
- **REST API design**
- **Authentication & authorization**
- **Database design**
- **Scalable systems**
- **Clean and maintainable software**
